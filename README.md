# AgendaFácil 📋 — Sistema de Disparo de Senhas via Telegram

Conecta sua conta do Telegram, seleciona o grupo de destino e o sistema envia a mensagem com a **senha** automaticamente no horário definido.

---

## ✅ Como Funciona

1. **Acesso** → Informa os últimos 4 dígitos do telefone
2. **Confirmação** → Revisa os dados preenchidos: grupo, pessoa, horário e contato
3. **Autorização** → Conecta com o Telegram e digita o código recebido
4. **Escolha o Grupo** → Seleciona em qual grupo do Telegram a senha será enviada
5. **Confirmação Final** → Valida que o grupo está correto
6. **✅ Pronto!** → O sistema dispara a mensagem da senha **automaticamente** no horário programado

---

## ✨ Funcionalidades

- ✅ Acesso por validação de telefone
- ✅ Confirmação prévia de todos os dados
- ✅ Integração e autorização com conta do Telegram
- ✅ Seleção do grupo de destino
- ✅ Confirmação de grupo antes do disparo
- ✅ Agendamento de horário exato para envio
- ✅ Disparo automático da mensagem com a senha
- ✅ Confirmação de conclusão do processo
- ✅ Interface responsiva — celular e computador

---

## 🎬 Diferencial

> **Não é envio manual:** você programa uma vez e o sistema executa sozinho. No horário marcado, a senha aparece no grupo do Telegram automaticamente.
